# Prod Guard

瀏覽器插件（Manifest V3）。在你設定的「正式環境」網域上，每次載入頁面或切回分頁，都會先蓋一層遮罩：「此為正式環境，點擊螢幕開始操作」。

## 安裝（Brave / Chrome / Edge）

1. 開啟 `brave://extensions`（Chrome 用 `chrome://extensions`，Edge 用 `edge://extensions`）。
2. 打開右上角「開發人員模式」。
3. 按「載入未封裝項目」，選這個資料夾。
4. 點工具列的插件圖示，在清單裡對預設網域按「授權」。

改過程式碼後，回到擴充功能頁，按 Prod Guard 卡片上的重新整理圖示。

## 使用

- 新增：輸入網域，或在該網站上按「加入目前網站」。瀏覽器會跳出授權視窗，只問那一個網域。
- 修改：直接改輸入框的文字，按「儲存」或 Enter。
- 刪除：按「刪除」。插件會一併收回那個網域的權限。
- 授權完成後，已經開著的分頁要重新整理才會出現遮罩。

## 結構

| 檔案 | 用途 |
|------|------|
| `manifest.json` | 插件設定。網站權限是 optional，一開始不碰任何網站。 |
| `background.js` | 讓清單、權限、已註冊的 content script 保持一致。 |
| `content.js` | 注入正式環境網頁，負責遮罩。 |
| `popup.html/js/css` | 工具列小視窗，管理網域清單。 |
| `shared.js` | background 和 popup 共用的小工具。 |

## 規則

- 只比對完整主機名稱。`app.example.com` 不含 `x.app.example.com`。
- 從同網站的其他頁面點進來時，不重複蓋遮罩。
- 分頁被切走時就先蓋上遮罩，切回來時不會閃一下內容。
